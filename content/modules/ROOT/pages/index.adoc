= Lab Overview

In this lab, we’ll explore *Red Hat Edge Manager*, a solution designed to deliver simple, scalable, and
secure management of edge devices and applications. With Edge Manager, you declare the desired
operating system image, host configuration and set of applications to run on a single device or an
*entire fleet of devices.* +

image::i1-overview.png[link=self, window=blank, width=85%, align="center"]

Edge Manager distributes these specifications to managed devices, where a local agent executes
configuration changes, monitors system health and reports status back to a centralized control
plane. Each device’s real-world state is evaluated against its declared configuration and, when drift
is detected, Edge Manager automatically initiates corrective actions to return the device to a
validated, compliant state. This ensures *consistent*, *deterministic* and *resilient* edge operations
even in *highly distributed, low-touch environments*. +

NOTE: https://github.com/flightctl/flightctl["Flight Control",window=_blank] is the upstream project and is accessible for anyone to explore outside of this Lab. Red Hat Edge Manager (RHEM) is the downstream offering. Throughout this lab, you will see references to 'flightctl' and you should treat these as analagous to Edge Manager.
