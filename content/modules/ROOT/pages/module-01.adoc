=== Configuring Edge Manager Authentication

Now that Edge Manager is installed we are going to configure authentication next.  Edge Manager supports multiple authentication providers.  In this lab, you’ll configure OpenID Connect (OIDC) in combination with a Pluggable Authentication Module (PAM) to authenticate users and authorize access:

image::m1-oidc-with-pam-overview.png[link=self, window=blank, width=100%]

At a high level, authentication works as follows:

. The user initiates a login from the Edge Manager UI or CLI 
. The Edge Manager API service directs the request to the PAM issuer, which acts as the OIDC authentication server
. The user authenticates with the PAM issuer
. An access token is issued, containing the role and org for the user
. Subsequent requests against the Edge Manager API utilize the token 

To configure Edge Manager to use OIDC and PAM authentication, you’ll make a few targeted updates to the Edge Manager configuration file located at: `/etc/flightctl/service-config.yaml`

. Instead of editing the the entire configuration file manually, we've made it easier to update service-config.yaml in this lab by copying and pasting the following commands (please do so now):
+
.Set environment variables for the RHEM Web UI and OIDC PAM endpoints (these variables reference OpenShift Routes that expose the RHEM Web UI and the PAM-based OIDC authentication service)
[source,sh,role=wrap execute,subs=attributes+]
+
----
WEBUI_URL="https://rhem-on-rhel-webui-wksp-{guid}-{user}.{openshift_cluster_ingress_domain}"
OIDC_PAM_URL="https://rhem-on-rhel-oidc-pam-wksp-{guid}-{user}.{openshift_cluster_ingress_domain}"
----
+
.Configure the OIDC issuer used by Edge Manager
[source,sh,role=wrap execute,subs=attributes+]
----
sudo sed -i \
  "s|^      issuer:.*|      issuer: ${OIDC_PAM_URL}/api/v1/auth|" \
  /etc/flightctl/service-config.yaml
----
+
.Configure redirect URIs for the RHEM Web UI. OIDC requires redirect URIs to be explicitly defined (this allows the authentication service to redirect users back to the RHEM Web UI after login)
[source,sh,role=wrap execute,subs=attributes+]
----
sudo sed -i '/pamOidcIssuer:/,/pamService:/ {
  /redirectUris:/! {
    /issuer:/a\
      redirectUris:\n\
        - '"${WEBUI_URL}"'/callback\n\
        - http://localhost:8080/callback
  }
}' /etc/flightctl/service-config.yaml
----
+
.Set BASE_UI_URL in UI env template (this configures the base URL used by the Edge Manager Web UI)
[source,sh,role=wrap execute,subs=attributes+]
----
sudo sed -i \
  "s|^BASE_UI_URL=.*|BASE_UI_URL=${WEBUI_URL}|" \
  /usr/share/flightctl/flightctl-ui/env.template
----
+
.Enable RHEM branding
[source,sh,role=wrap execute,subs=attributes+]
----
sudo sed -i \
  -e '/^IS_RHEM=/d' \
  -e '$aIS_RHEM=true' \
  /usr/share/flightctl/flightctl-ui/env.template
----
+
.Restart RHEM services
[source,sh,role=wrap execute,subs=attributes+]
----
sudo systemctl restart flightctl.target
----

NOTE: Given the timing of the Edge Manager GA release and this lab’s creation, an upstream version equivalent to GA 1.0 is used. As a result, the RHEM UI branding shown above is explicitly enabled (via IS_RHEM=true) so that you see the GA RHEM UI (branding) rather than the upstream Flight Control UI.

=== Creating Users and Groups

Now that Edge Manager is configured with the appropriate issuer and redirect URIs, the next step is to create users and groups for authentication and authorization

. Create users and groups by issuing the following podman exec commands against the flightctl-pam-issuer container
+
.Create the groups for global administrators, operators and viewers
[source,sh,role=wrap execute,subs=attributes]
+
----
sudo podman exec -i flightctl-pam-issuer groupadd flightctl-admin
sudo podman exec -i flightctl-pam-issuer groupadd flightctl-operator
sudo podman exec -i flightctl-pam-issuer groupadd flightctl-viewer
----
+
.Create your user account
[source,sh,role=wrap execute,subs=attributes]
----
sudo podman exec -i flightctl-pam-issuer adduser {user}
----
+
.Set your user account password
[source,sh,role=wrap execute,subs=attributes]
----
sudo podman exec -i flightctl-pam-issuer sh -c 'echo "{user}:redhat123" | chpasswd'
----
+
.Assign the Edge Manager administrator role to your user account
[source,sh,role=wrap execute,subs=attributes]
----
sudo podman exec -i flightctl-pam-issuer usermod -aG flightctl-admin {user}
----
